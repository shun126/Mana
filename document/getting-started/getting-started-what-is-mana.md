# Mana とは

Mana は、ゲーム内のキャラクターやイベントなど、複数の処理を協調させて記述するためのスクリプト言語です。

ゲームでは、NPC が歩く、別の NPC が会話する、扉が開く、カメラが動く、といった複数の出来事が同じ時間の中で進みます。Mana は、このような処理を Actor と Action という単位に分け、Actor 同士が Request を送り合うことで連携できるように設計されています。

## Mana はテキストで書く言語

Mana のプログラムは、テキストファイルに文字として記述します。Mana のソースファイルには通常 `.mn` という拡張子を使います。

例えば、次のようなコードが Mana のプログラムです。

```mana
actor Hello
{
    action main
    {
        print("Hello, Mana!\n");
    }
}
```

今は `actor` や `action` の意味が分からなくても問題ありません。後のチュートリアルで一つずつ説明します。

## Mana はコンパイルして実行する

Mana のソースコードは、そのまま Mana VM が実行するわけではありません。まず Mana Compiler がソースコードを読み取り、Mana VM が実行できる Program Image に変換します。この変換を **コンパイル** と呼びます。

```text
Mana Source (.mn)
      |
      v
Mana Compiler
      |
      v
Program Image
      |
      v
Mana VM
      |
      v
    実行
```

Mana はスクリプト言語ですが、ソースコードを逐次解釈して実行するだけの言語ではありません。コンパイル段階を持つことで、文法や名前の間違いなどを実行前に検出しやすくしています。

## ゲーム側の処理と役割を分ける

Mana だけですべてのゲーム処理を書くことを目的にはしていません。

描画、物理、サウンド、アニメーションなどの複雑な処理はゲーム本体側へ任せ、Mana では「いつ」「誰が」「何をするか」といったイベントや行動の組み合わせを記述できます。

## Mana の中心となる3つの言葉

今後よく登場する言葉だけ、先に紹介します。

- **Actor**: 独立して行動する実行主体
- **Action**: Actor が行う処理
- **Request**: 別の Actor に Action の実行を要求する仕組み

この3つが Mana の基本です。
