# テキストでプログラムを書く

このページでは、Mana を始める前に知っておきたい最低限の言葉を説明します。

## プログラムは文字で書ける

Mana では、コンピュータに行わせたい処理を文字として記述します。この文字列を **ソースコード** と呼びます。

ソースコードは特別なバイナリデータではなく、テキストエディタで編集できるテキストです。Mana では通常、`.mn` をソースファイルの拡張子として使います。

```mana
actor Hello
{
    action main
    {
        print("Hello!\n");
    }
}
```

この例では、`print("Hello!\n");` が一つの処理を表しています。`;` は文の終わりを示します。`{` と `}` で囲まれた範囲は、複数の処理をまとめるブロックです。

## ソースコードをコンピュータが確認する

人が書いたソースコードには、入力ミスや文法上の間違いが含まれることがあります。Mana Compiler はソースコードを読み、構文や名前を確認しながら Program Image へ変換します。この処理を **コンパイル** と呼びます。

コンパイル中に問題が見つかると、Mana Compiler はエラーを報告します。エラーを修正して、もう一度コンパイルします。

## VM がプログラムを実行する

コンパイルされた Program Image を実際に処理するのが **Mana VM** です。VM は Virtual Machine の略で、Mana の命令を実行するための実行環境です。

つまり、基本的な流れは次のようになります。

```text
ソースコードを書く
      ↓
コンパイルする
      ↓
エラーがあれば修正する
      ↓
Mana VM で実行する
      ↓
意図した動作か確認する
```

コンパイルに成功しても、意図した動作になるとは限りません。実際に動かして確認し、必要ならソースコードを直して再びコンパイルします。

## 今は覚えなくてよいもの

変数、型、条件分岐、繰り返し、関数などは後のチュートリアルで説明します。最初の段階では「Mana のプログラムはテキストで書き、コンパイルしてから VM が実行する」と理解できれば十分です。
