# 処理を繰り返す

同じ処理を何度も書く代わりに、Mana では繰り返し構文を使えます。

ここでは、まず `while` と `for` を学びます。

## このページで分かること

- `while` で条件が成立している間、処理を繰り返せる
- `for` で回数を数えながら繰り返せる
- `break` で途中終了できる
- `continue` でその回の残りを飛ばせる
- 終了条件のない繰り返しに注意する

## `while` の基本

次の例では、`count` が 0 より大きい間、処理を繰り返します。

```mana
actor Counter
{
    action main
    {
        int count = 3;

        while (count > 0)
        {
            print("count: %d\n", count);
            count--;
        }
    }
}
```

実行結果は次のようになります。

```text
count: 3
count: 2
count: 1
```

`count--` は `count` の値を 1 減らす書き方です。

次の書き方と同じ目的で使えます。

```mana
count = count - 1;
```

## `while` は条件を先に調べる

`while` は、繰り返しを始める前に条件を確認します。

```mana
while (condition)
{
    // 繰り返す処理
}
```

条件が最初から成立していなければ、中の処理は一度も実行されません。

## 回数が決まっているなら `for`

「3回実行する」のように、回数を数えながら繰り返す場合は `for` が便利です。

```mana
actor Counter
{
    action main
    {
        for (int i = 0; i < 3; i++)
        {
            print("i: %d\n", i);
        }
    }
}
```

実行結果は次のようになります。

```text
i: 0
i: 1
i: 2
```

`for` の括弧の中は、大きく3つに分かれています。

```text
for (最初に行う処理; 続ける条件; 1回ごとに行う処理)
```

今回の例では、

```mana
for (int i = 0; i < 3; i++)
```

なので、

1. `i` を 0 にする
2. `i < 3` の間だけ続ける
3. 1回終わるごとに `i` を 1 増やす

という意味になります。

## `break` で途中終了する

条件によって、繰り返しを途中で終わらせたい場合は `break` を使えます。

```mana
for (int i = 0; i < 10; i++)
{
    if (i == 3)
    {
        break;
    }

    print("i: %d\n", i);
}
```

この場合、`i == 3` になったところで `for` を終了します。

## `continue` でその回だけ飛ばす

`continue` は、現在の繰り返しの残りを実行せず、次の回へ進みます。

```mana
for (int i = 0; i < 5; i++)
{
    if (i == 2)
    {
        continue;
    }

    print("i: %d\n", i);
}
```

`i == 2` の回だけ `print` が実行されません。

## 終わらない繰り返しに注意する

例えば次のコードでは、`count` が変化しないため条件がいつまでも成立し続けます。

```mana
int count = 3;

while (count > 0)
{
    print("loop\n");
}
```

このような状態を **無限ループ** と呼びます。

意図的な常駐処理を作る場合を除き、繰り返しには「いつ終わるのか」が分かる条件を用意してください。

Mana には Actor の実行を他へ譲る `yield()` や、専用の `loop` 構文もあります。Actor のスケジューリングと関係するため、これらは後のチュートリアルで扱います。

## `do-while` について

Mana は `do-while` もサポートしています。

`while` と違い、処理を一度実行してから継続条件を調べます。入門では `while` と `for` を使えるようになれば十分です。

## ここまでで覚えておきたいこと

- `while` は条件が成立している間繰り返す
- `for` は回数を数えながら繰り返す処理に向いている
- `break` は繰り返しを終了する
- `continue` はその回の残りを飛ばす
- 終了条件が変化しないコードは無限ループになる可能性がある
