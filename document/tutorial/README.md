# Mana チュートリアル

このチュートリアルでは、小さなプログラムを実際に書きながら Mana の言語機能を学びます。

まずは Mana の中心となる Actor / Action / Request から始め、その後で変数、条件分岐、繰り返し、関数を学びます。基本的なプログラミング要素を身につけた後、Priority や同期など Mana 固有の実行モデルへ進みます。
