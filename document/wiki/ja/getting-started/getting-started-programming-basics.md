# テキストでプログラムを書く

ここでは、コードを書く場所と、コードを実行する場所を区別できるようにします。まだ Mana のツールを用意していなくても読めます。

## エディタとターミナル

**テキストエディタ**は文字を入力してファイルへ保存するアプリです。Mana のコードは、文字の色や段落の装飾を保存する文書形式ではなく、プレーンテキストとして保存します。

**ターミナル**は、コマンドを入力してツールを動かす画面です。Windows では PowerShell、Linux ではシェルを使います。

この教材では、コード欄の直前に用途を書きます。

**ソースコードの例 — エディタに入力する内容：**

```mana
actor Hello
{
    action main
    {
        print("Hello, Mana!\n");
    }
}
```

**実行コマンドの例 — ターミナルに入力する内容：**

```text
mana hello.mn
```

コマンドをソースファイルへ書き込む必要はありません。`mana` がツール名、`hello.mn` が処理するファイル名です。ツールの具体的な指定方法は次の準備ページで設定します。

## ファイル名と保存場所

`hello.mn` の `.mn` は **拡張子**です。ファイルの用途を示す名前の末尾で、Mana のソースファイルでは通常これを使います。

保存時は次の点を確認します。

- ファイル名は `hello.mn` にする。`hello.mn.txt` になっていないか確認する。
- 文字コードは UTF-8 にする。この教材の例は UTF-8 で保存して使う。
- 保存したフォルダーを覚えておく。フォルダーは **ディレクトリ**とも呼ぶ。
- 編集後は保存する。コマンドが読み込むのは、ディスクへ保存した内容。

Windows で拡張子が見えない場合は、エクスプローラーでファイル名拡張子の表示を有効にしてください。

## 記号にも意味がある

`print("Hello, Mana!\n");` は、文字を表示する処理です。

| 書き方 | 役割 |
| --- | --- |
| `"Hello, Mana!\n"` | 表示する文字列。文字列は半角の `"` で囲む |
| `\n` | 文字列の中で改行を表す |
| `;` | この文の終わり |
| `{` と `}` | 定義や処理の範囲を囲む |

括弧やセミコロンなどの記号は半角で入力します。`Hello` と `hello` のような大文字・小文字も区別します。

行頭の空白は **インデント**と呼びます。どの範囲に属する処理かを読みやすくするため、教材では内側へ入るたびに空白を4個増やしています。インデントしても、必要な括弧や `;` を省略できるわけではありません。

`//` から行末までは **コメント**です。人が読む説明を書けます。

**Action の中に書く例：**

```mana
// 案内の文字を表示する
print("Welcome!\n");
```

## 書く、保存する、実行する、確かめる

プログラムは、一度で完成させなくても構いません。小さく変更して、結果を確かめます。エラーは入力した内容を見直す手がかりです。エラーの読み方も後で練習します。
