# Mana ドキュメント

Mana は、ゲーム内のキャラクターやイベントの進行を、テキストで記述するプログラミング言語です。処理を Actor と Action に分け、Request で連携させます。

初めての方は、文字を表示するところから始めて、会話して門を開ける小さなイベントを作りましょう。プログラミング未経験の方も、ソースファイルの作り方、コンパイル、エラーの直し方から学べます。

2. [テキストでプログラムを書く](./getting-started/getting-started-programming-basics.md)
3. [Mana を使う準備](./getting-started/getting-started-installation.md)
4. [はじめての Mana プログラム](./getting-started/getting-started-first-program.md)
5. [コンパイルと実行・エラーの直し方](./getting-started/getting-started-compile-and-run.md)

続いて [チュートリアル](./tutorial/README.md)で、Actor と Action を使ったイベントを作ります。ツールとターミナルの操作に慣れている方は、[最初のプログラム](./getting-started/getting-started-first-program.md)から試せます。
