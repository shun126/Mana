# Mana Documentation

Mana is a programming language for describing, in text, how characters and events unfold in a game. You split the work into Actors and Actions and connect them with Requests.

If you are new, start by printing some text, then build a small event in which a guide talks and a gate opens. Even if you have never programmed before, you can learn from the beginning: how to create a source file, compile it, and fix errors.
